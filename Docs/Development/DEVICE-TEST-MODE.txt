사용 방법
로비 하단 테스트 모드 → 각 선택 버튼을 눌러 순환 → 선택한 설정으로 시작.
- 진입: 보스 바로 시작 / 일반 주행·장애물·보스.
- 보스: Resources/Data/BossConfigs에 등록된 보스 목록. 현재 도시의 쥐왕1종.
- 패턴: 해당 체력 구간의 전체 무작위 또는 특정 패턴 고정.
- 난도: 선택한 체력 구간의 요구 수·시간을 고정하고 보스는 최대 체력으로 시작.
게임 중 상단 테스트 설정 → 설정 변경 후 재시작, 체력 회복, 보드 초기화.
설정 메뉴를 열면 진행 중 전투를 일시정지하고 닫으면 재개. 이미 정지 상태였다면 유지.
피버 중 보드 초기화는 임시 보드 복원을 보호하기 위해 실행하지 않음.
색 선택창이 열린 동안 테스트 설정을 열지 않음. 색 선택을 먼저 마칠 것.
일반 로비로 버튼 또는 기존 홈 버튼으로 나가면 테스트 모드 해제.

저장 정책

최고점은 NyanLink_TestBestScore 키로 분리. 일반 최고점 및 저장 파일을 덮어쓰지 않음.
앱을 다시 실행하면 일반 모드로 시작. 테스트 세션을 자동 이어하지 않음.
테스트 폴더는 증거 보존을 위해 자동 삭제하지 않음.
런타임 보스 설정을 복제하여 사용. 원본 에셋 수정 없음.
