7. 재현
같은 프로젝트 Unity는1개만 실행. 그래픽 검사는 -batchmode/-nographics/-quit 없이, 검사 도구가 스스로 종료. 다른 프로젝트 Unity 종료 금지.
통합: NYANLINK_KO_QA=1 NYANLINK_UI_QA=1 NYANLINK_CONCEPT_QA=1 NYANLINK_SESSION08_OUTPUT=<새출력> Unity -buildTarget StandaloneOSX -projectPath <프로젝트> -executeMethod NyanLinkSession08Validation.Run -logFile <새로그>
Cold: 동일출력 ... NyanLinkSession08Validation.RunColdContinue
회귀05/07: NYANLINK_SESSION05_OUTPUT 또는 NYANLINK_SESSION07_OUTPUT=<새폴더>,07은 NYANLINK_UI_QA=1,해당번호Validation.Run.
빌드: NYANLINK_BUILD_PATH=Builds/KoreanUI/NyanLink.app NYANLINK_BUILD_OUTPUT=<새출력> Unity -batchmode -quit ... NyanLinkSession08Build.Build
실행: .app/Contents/MacOS/NyanLink -nyanSmoke <격리출력> -logFile <새로그>. Development의 명시 QA옵션만 활성, Release 제외.
NyanLinkKoreanFontPipeline.Prepare는 최초 생성용. 이미 생성된.asset이 있으면 GUID보호를 위해 거부. 일반 실행/빌드에는 재생성 불필요. 재생성 시 기존.asset/.meta/출처부터 별도 보존하고 GUID연결을 유지하는 재생성 절차를 마련할 것.
기존 검증 출력은 덮어쓰지 않고 새폴더 지정. 테스트 sandbox/예제profile을 사용자saves로 복사 금지.
