수행 순서와 기대 결과
1. 업데이트 및 기존 기록 (D-002)
   APK 설치 전후 profile 파일 바이트를 비교. 실행 전 기존 저장이 유지되어야 함.
   로비 진입, 기존 진행이 있으면 이어하기·장비/코인 표시 확인.
2. 방향·화면·터치 (V-021/I-011/D-001)
   기기를 세로/가로로 직접 돌려 로비·준비·플레이·정지·홈 복귀·콜드 실행 확인.
   게임 세로 방향 유지, 39칸·한글·HUD·버튼 잘림 없음. OS 표시와 앱 방향을 구분 기록.
   손가락 드래그·되돌리기·연결 해제·오입력을 직접 확인.
3. 러닝 선입력과 연출 (D-005, V-023/V-024)
   빨강/파랑/노랑 예고→선입력→입력 마감→캐릭터 앞 연출 확인.
   정답 직후 달리기 유지, 장애물 연출 지점에서 액션1회.
   마감 후 늦은 정답은 실패 유지, 늦은 오답은 예약된 성공 유지.
   성공/실패 대기 구간의 정지·재개와 색 선택 창 복귀도 확인.
4. 보스 순서 (D-004)
   첫3칸 패턴의 번호·현재 금색 테두리·완료 회색 표시 확인.
   그로기→강화4/5칸→오답/시간초과→다음 패턴 초기화·정지/재개 확인.
   보드/타이머/UI 겹침 없음, 연속 같은 색 순서도 구분 가능해야 함.
5. 무보정 플레이 및 성장 (V-002/D-001/D-002)
   실제 손으로 장애물3개→보스→승리 또는 패배→재도전.
   클리어 시 보상→장착/강화→다음 플레이 능력치 반영 확인.
   무보정 클리어가 불가능하면 장애물/보스와 막힌 이유를 기록하고 완료로 처리하지 않음.
6. 오디오 및 앱 수명 (V-012/D-001/D-002)
   BGM·매칭3티어·아이템·피격·승패를 사용자가 실제 청취.
   홈·잠금→복귀 시 정지 상태와 오디오 확인.
   저장 경계 확인 후 강제종료·재실행→보드/HP/점수·코인/장비 복원.
   마지막 체크포인트 이후 진행분은 되돌아갈 수 있음. 재지급 없어야 함.
