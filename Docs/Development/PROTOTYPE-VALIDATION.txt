화면·초기값 조정 기록
- 안전 영역 대응 없음→각 루트 Overlay Canvas의 SafeArea 컨테이너 + 동일 Screen.safeArea를 사용하는 카메라. 기기 Insets의 실제 값은 실기기 D-001에서 확인.
- 퍼즐 카메라 하단60% 전체→하단 논리60% 중 보드53.5%·점수/체인 티어 여백6.5%. 상단 러너40%는 그대로. 보드39칸/게임 좌표는 변경 없음.
- 기존 전체 화면 Main Camera의 중복 보드 출력→같은 카메라를 마스크0/깊이-100/단색 배경 전용으로 사용. Runner는TopView, Puzzle은그외 레이어로 분리. 가장자리의 중복 보드가 실제 PNG에서 재현돼 수정.
- 기존 점수/체인 상단→퍼즐 위 전용 줄. 플레이어HP·진행률·Pause·보스HP/페이즈/순서·타이머·경고를 상단에서 분리. 결과/준비는 불투명 배경으로 중간 타일 애니메이션이 가독성을 가리지 않음.
- 선택선 최소0.015→0.035 world units. 작은 화면에서 같은 색 타일 간 연결을 읽기 쉽게 함. 기존 LineFlow 셰이더·머티리얼은 보존하고 Resources 참조로 Player 포함 보장.
- Stumble 시각 흔들림의 Random.Range→수학적 진동. 시각 효과가 퍼즐/보스용 Unity.Random 상태를 소비하지 않게 분리.
- 무음/미연결→간단한 AI 작성 합성 테스트 WAV7개, PCM·미리 로드. 매칭3티어/아이템/피격/승패. 기존 공개 AudioClip 필드를 유지하므로 이후 음원 교체 가능. 최종 음악/캐릭터 보이스·사운드 디자인 아님.
- HP100, 길이250/속도5=50초, 장애물20·보스실패20, 보스120/3색/10초/그로기5초, 장비/보상/강화비는 유지. 자동 검사 속도·보드/HP 배치를 사람 난이도 근거로 쓰지 않음. 충분한 사람/실기기 자료 없이 경제·전투 수치를 임의 변경하지 않음.
