9. 다음 세션의 시작 방법과 주의점
- 세션 02 진행 가능. 이 인수인계와 WORK_ITEMS를 먼저 읽고 정확한 Unity 버전으로 컴파일을 재확인한다.
- 첫 Play부터 검사할 때는 Editor 플레이 모드를 완전히 종료 후 Main에서 시작한다. 같은 플레이 중 재진입 문제 I-002를 첫 진입 문제와 혼동하지 않는다.
- 세션 02는 I-001의 좌표·39칸·입력·카메라를 다루고, 매니저 생명주기/전투/저장/성장을 완료했다고 가정하지 않는다.
- 동시 개발 채팅이나 같은 프로젝트의 Unity 두 인스턴스를 열지 않는다. CLI batch 검증 전에 프로젝트 Editor를 닫는다.
- CLI smoke는 그래픽이 필요한 Editor 실행이다. -batchmode/-nographics/-quit을 Run/RunLifecycle에 붙이지 않는다(도구가 비동기로 플레이 후 자체 종료). Audit에는 -batchmode -quit 사용 가능.
- 기존 저장 구현은 읽기 실패 시 파일 삭제 코드가 있으므로 세션 06 이전에 사용자 저장 파일로 손상 복구 테스트를 하지 않는다.
- 현재 변경은 자동 커밋하지 않았고 원격에 올리지 않았다. 백업과 session-changes.json을 근거로 이번 세션 차이만 검토할 수 있다.
