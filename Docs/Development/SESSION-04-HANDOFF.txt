2. 완료한 규칙과 강화 선택
- TimeAttack 1종만 활성. 기존 RhythmNote/ColorQuota/MemorySequence는 코드·컴포넌트를 보존하되 미연결/비활성 유지.
- 보스 HP120, 전체 색 순서 공개, 초기 순서3/제한10초, 오순서·시간 초과 실패20, 성공 시 그로기5초. 패턴 성공 고정 피해 없음.
- 6색 전체에서 순서 생성. 각 단계 다음 요구 색을 보드 보정 API에 등록하고 전환/리필 시 재검사. 보호 아이템은 덮어쓰지 않음.
- 패턴/패턴 사이 대기에서 아이템 효과·새 아이템 생성 금지, 기존 아이템은 체인 입력에 포함할 수 있으나 제거/점수/회복에서 보존. 두 보존 아이템의 연결도 순서 입력은 가능하되 실제 제거0→점수0/회복0. 단독 터치는 패턴 입력이 아님.
- 한 매칭의 실제 고유 제거 수로 점수·회복. 체인 티어는 직접 연결 2~4 x1, 5~8 x2, 9+ x4. 점수=제거수×10×티어, 일반 회복=제거수×0.3. 연속 콤보/치명타는 활성 계산에서 제외.
- 그로기 공격=직접 연결 수×공격력 계수1×그로기 배율2, 주황만 추가x2. 폭발/라인 추가 제거는 공격 수에 포함하지 않음.
- 공격 버프는 높은 값만 보관하고 다음 유효한 공격 한 번에 소모. 청록/패턴 성공/패턴 입력은 소모하지 않음. 청록은 직접 피해0, 다음 보스 실패1회 방어(중복 비축 없음).
- 주행에서 얻은 다음 공격 버프·청록 방어권은 주행 Pause/Resume와 Boss 진입을 거쳐 유지. 새 게임/재시작/Result에서 초기화.
- HP는 즉시 갱신. 공개 ApplyDamage로 모든 피해 공급자가 모이며 HP0 처치 플래그를 HP 이벤트보다 먼저 확정하여 재진입/중복에도 즉시 단일 승리. 별도 지연 처치 코루틴 없음.
- 패턴 성공 입력 자체가 동일 이벤트에서 그로기 공격으로 이중 집계되지 않도록 그로기 개방은 다음 게임 프레임에 수행.
- 보스 중 HP 자연 감소·러너 경과 시간 증가 정지. 패턴/그로기/전환 대기 모두 게임 Pause 때 보존, Resume는 이전 보스 단계·HP·순서·시간 유지. Result에서 전투/입력 정지.
- 강화 선택: 기존 HP 임계값50%/20% 유지. 각 임계점마다 순서+1/시간-1초, 최소 제한6초. 현재 단계는 3색10초→4색9초→5색8초. 임계값을 그로기 중 넘겨도 종료 후 적용하며 여러 임계값을 넘기면 해당 단계까지 한 번에 반영. 같은 TimeAttack 유지.
- 패턴 사이 기본 간격1초를 데이터화. 실패는 그로기 없이 다음 패턴. 시간 정지 API는 보스 제한 시간(그로기/간격 포함)만 멈추며 게임 Pause와 구분.
- 보스 HUD를 기존 씬에서 활성화하고 HP/순서/타이머/강화 단계/그로기 표시 연결. 보스·플레이어 HP 간격 조정. 기존 그로기 오버레이는 보드와 겹쳐 숨기고 타이머/안내로 표시. 점수 아래 CHAIN/TIER 표시 추가. 한글 폰트·전체 UI 정비는 후속.
- 기존 ColorEffectMappingData가 TileColor 0..5와 ItemEffectType None 포함0..6을 같은 숫자로 연결하던 오류 발견. GUID를 유지하고 effect를1..6으로 수정. 노랑이 TimeFreeze로 연결되던 원인을 해결했으며 그로기 확장 제거 검증에 필요했음.

- TryApplyGroggyAttack(connected,removed,color): 유효한 매칭 결과 하나만 전달. 실제 제거>0/연결>=2/그로기 필요. 공격 산식에는 connected만 사용, 청록은 방어권만 획득. 내부에서 최대 버프를 한 번 소모. 현재 OnMatchCompleted 구독이 호출하므로 세션 05에서 같은 결과를 다시 호출하지 말 것.
- GrantAttackBuff(bonus), GrantFailureShield(): 주행 또는 보스 그로기에서만 획득, 패턴/Pause/Result에서는 거부. PendingAttackBonus/HasFailureShield 읽기. 주행에서 Boss 진입까지 유지, Briefing/Result에서 초기화.
- GroggyRemaining/TimerFreezeRemaining/TimersFrozen 읽기. FreezeTimersFor(seconds)는 현재 그로기에서 획득하는 보스 시계 정지 API. 남은 값과 새 값 중 max. 세션 05는 기존 OnTimeFreeze를 이 API 및 StaminaManager.PauseDecay에 연결하고 주행→보스 시 효과 잔여 시간 동기화 정책을 구현·검증할 것. 이 세션에서 이벤트 자동 연결/6종 아이템 완성을 수행한 것은 아님.
TimeAttackPattern:
