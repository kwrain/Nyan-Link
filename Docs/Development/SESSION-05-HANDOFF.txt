2. 완료한 규칙
생성·연쇄:
- 직접 연결 5~8개 Lv1, 9개 이상 Lv2, 마지막 셀 생성. 종류별 최대2개이며 다른 종류 합계의 별도 슬롯 제한 없음.
- 연쇄로 기존 아이템을 모두 소비한 뒤 남아 있는 같은 종류 수를 기준으로 생성 한도를 검사. 한도면 새 생성만 생략, 제거/점수/회복은 정상 처리.
- 단독 마우스/터치 Release에서도 아이템 사용. 정상 타일 1개는 사용 안 함. 같은 색 체인에 포함된 기존 아이템도 사용.
- 기존 타일만 대상으로 폭발/라인을 큐로 전파하고 셀별 1회 발동. 실제 고유 제거 수를 HashSet으로 집계. 모든 기존 효과가 끝난 후 한 번 집계·제자리 리필·새 아이템 생성. 새 타일/아이템은 해당 연쇄에서 다시 제거/발동하지 않음.
- 단독 사용은 체인 티어x1, 실제 제거수×10 점수 및 ×0.3 회복. 별도 ItemUseCompleted 이벤트로 색상 액션/장애물 정답/보스 순서 입력/그로기 직접 공격과 구분.
6종×2티어:
- Recovery: 최대 HP10%/30% 즉시 회복, 일반 제거 회복 별도.
- TimeFreeze:3/7초. 자연 감소·보스 패턴/그로기/전환 대기만 정지. 주행 경과/진행·입력·타일 애니메이션·장애물 이동은 유지. 남은 시간과 새 효과 중 max, 합산 안 함.
- Blast: 육각 반경1/2. LineClear: 가로1줄/3축 라인. 기존 아이템을 맞히면 해당 종류/레벨의 효과를 한 번 연쇄.
- PowerUp: 다음 유효 보스 공격+50%/100%. 높은 값만 유지. 단독 효과 자체는 색상 공격이 아니며 그로기 직접 공격 이벤트에서 한 번 소모. 주행에서 보스 진입까지 유지.
- ColorShift: Lv1 무작위6색 중1색, Lv2 실제6색 UGUI 선택. 모든 타일 색을 바꾸되 기존 아이템의 종류·레벨·위치는 보존.
- 보드 요구 색 인접 쌍 확보가 최종 우선. 선택 색과 장애물/패턴 요구 색이 다르면 보정에 필요한 일반 타일 최소 쌍은 요구 색으로 돌아갈 수 있음. 이 보정은 아이템 종류/레벨을 바꾸지 않음.
상태/보스:
- 색상 선택은 별도 ColorSelection 상태와 timeScale0. 입력/진행/장애물/보스·효과 시간 보존. 선택 후 원래 Runner/Boss 상태로 IsResuming=true 발행, 초기화 없이 복귀.
- 선택 중 PAUSE→RESUME는 같은 선택창으로 돌아가며 계속 timeScale0. RESTART/HOME은 선택 콜백·남은 효과를 취소하고 새 게임/로비로 이동.
- 같은 연쇄에 청록Lv2가 여러 개 있으면 기존 발동 순서대로 선택하고 마지막 선택까지 게임 정지 유지. 매칭 제거/집계/리필은 다시 실행하지 않음.
- 매칭이 먼저 보스 HP0/Result를 만들면 대기 청록 선택을 취소하고 승리를 유지. 결과에서 입력/진행 정지.
- 보스 패턴/전환 대기 중에는 아이템 효과·생성 금지. 체인에 기존 아이템을 보존, 실제 제거수만 점수/회복. 단독 사용은 패턴 단계 진행 안 함. 보존된 아이템2개 연결은 순서 입력 가능하되 제거0/점수0/회복0.
- 시간 정지의 유일한 시계는 StaminaManager.DecayFreezeRemaining. Boss.TimerFreezeRemaining은 같은 값을 읽으므로 주행→보스 이월/정지/재개에서 두 시계가 어긋나지 않음.

4. 데이터·API·이벤트 계약 (세션06 필수)
TileInstance:
- Color는 현재 연결 색, State는 Normal/ItemLv1/ItemLv2, ItemType은 기존 아이템 효과 정체성. ColorShift 뒤 Color와 ItemType은 다를 수 있음.
- 생성 시 원래 색 매핑으로 ItemType 설정. RecolorAll은 Color만 바꿈. State→Normal은 ItemType=None, Item→Lv변경은 기존 종류 유지. Reset은 종류 초기화.
- SetItemType(type)은 상태가 아이템일 때 명시적인 종류 복원 지점. DefaultItemType(color)은 신규/구형 데이터 폴백용.
- 세션06 저장은 위치/Color/State뿐 아니라 ItemType도 반드시 저장·복원할 것. 재색칠된 아이템을 Color로 다시 유추하면 종류·한도가 손상됨. 이번 세션에서 저장 구현을 선행하지 않음.
PuzzleBoardManager:
- CountItemsOfType는 Color가 아닌 ItemType 기준.
- RecolorAll(color): 활성 타일 전체 색만 변경, 타입/레벨/위치 보존, 마지막에 EnsureRequiredColorPair. 선택/보스 요구 색과의 정합을 이 경로로 유지.
TileMatcher:
- ProcessMatch(List<Vector3Int>) 기존 진입 유지, TryUseItem(cell) 단독 사용 API(bool).
- IsResolving은 동기 연쇄부터 모든 청록 선택 종료까지 true, 새 처리 거부. Briefing/Result/OnDisable은 큐 취소.
- LastDirectCount/LastRemovedCount/LastActivatedCount는 마지막 요청 결과의 읽기 전용 검사 값.
- OnItemActivated는 각 기존 원본 아이템당 한 번, 기존 보드를 읽는 시점(제거/리필 전). 관찰 전용이며 구독자가 보드를 재작성하지 말 것.
- OnColorShift는 전체 리필+RecolorAll 후 알림. 구독자가 같은 색 적용/제거/집계를 다시 실행하지 말 것. 청록 적용은 큐 순서대로, 신규 타일도 최종 색을 얻지만 제거/효과는 재진입하지 않음.
ScoreManager/GameEvents:
- AddScore(...,bool isItemUse=false) 선택 인수 추가. 기존 체인은 기존 OnMatchCompleted 한 번. 단독은 OnItemUseCompleted(scoreGained,actualRemoved) 한 번, OnMatchCompleted를 발행하지 않음.
- StaminaManager는 두 완료 이벤트 각각 해당 제거수 회복. 하나의 요청에 두 이벤트를 모두 발행하면 안 됨.
- OnItemActivated(sourceCell,type,level) 추가. 기존 OnRecovery/OnTimeFreeze/OnPowerUp 서명 유지.
시간/선택:
- StaminaManager는 OnTimeFreeze→PauseDecay를 구독. active Runner 또는 Boss 그로기에서 아이템 획득. DecayFreezeRemaining 하나를 active Runner/Boss에서만 감소. ColorSelection/Paused/Result에서 효과 잔여 시간도 보존. 새 게임 ResetStamina가 초기화.
- Boss.FreezeTimersFor는 같은 Stamina 시계로 위임. Boss 시작/종료에서 주행 효과 시계를 임의로0으로 만들지 않음.
- GameState.ColorSelection을 enum 맨 뒤에 추가하여 기존 직렬화 인덱스0~4 유지.
- GameManager.BeginColorChoice/CompleteColorChoice가 직전 Runner/Boss를 보존. PauseGame은 ColorSelection도 허용, ResumeGame은 그 상태일 때 timeScale0 복귀. 색 선택 완료는 IsResuming=true 상태 이벤트를 발행하여 보스 재시작 방지.
- ColorSelectionPanel.Show(Action<TileColor>), ColorButtons[6], IsOpen. 중복 Release/Paused 상태 버튼 호출은 무시. 선택 큐는 미완료 트랜잭션의 일시 UI이며 재시작/씬 이탈 시 폐기.
- 세션06은 매 타일/애니메이션이 아닌 승인된 구간 경계 저장. 재색칠 종류, 주행 가속/시간 정지 잔여, 보스 버프/방어권 및 다음 단계 등을 저장해야 함. 구간 저장에 선택 중인 콜백 자체를 직렬화하지 말 것.
