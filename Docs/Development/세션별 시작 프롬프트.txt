없음. 현재 작업 상태를 직접 확인해줘.

공통 작업 원칙:
- 기존 코드·리소스와 .meta 연결을 유지하고 필요한 부분만 정비해줘. 사용자 미커밋·미추적 변경을 지우거나 덮어쓰지 마.
- 실제 작업 경로와 Git 상태, 적용되는 AGENTS.md를 먼저 확인해줘. 이전 채팅의 기억 대신 파일과 현재 코드를 근거로 작업해줘.
- 선행 완료가 누락됐으면 독립적인 조사·준비는 진행하되 의존 기능이 완료됐다고 가정하지 말고 무엇이 필요한지 알려줘.
- 보류 기능은 기존 코드를 보존하고 활성 플레이 경로에서 제외해줘. 전체 재작성, 불필요한 패키지 삭제, 승인 없는 규칙 변경을 하지 마.
- 이번 범위에서 필요한 테스트와 Unity 실행 검증을 수행해줘. 실제 실행하지 못한 검증은 명시하고 통과로 보고하지 마.
- 자동 커밋·푸시·배포나 추가 채팅 생성은 하지 마. 다음 세션 구현까지 범위를 확장하지 마.

이번 작업:
현재 미커밋·미추적 파일을 포함한 작업 상태를 먼저 조사하고 복구 가능한 백업을 프로젝트 밖의 쓰기 가능한 위치에 만들어 경로와 포함 범위를 기록해줘. 기존 변경을 되돌리거나 자동으로 커밋하지 마.
Unity 버전과 패키지, Main/Game 씬, 스크립트 GUID, 중복 EventSystem·싱글톤, StageData·BalanceData·보스 참조를 확인해줘. 시작을 막는 컴파일·누락 참조를 우선 수정하고 StageData ID와 테스트 데이터 경로를 유효하게 만들어줘. 이후 세션의 전투·아이템·성장 기능까지 선행 구현하지 마.
가능하면 Unity 컴파일과 Main→Game 진입을 검증하고, 실행 불가 시 정확한 이유와 대체 검증을 남겨줘. 백업 복구 방법과 현재 재현 가능한 문제 목록을 다음 세션에 넘겨줘.

완료 기준:
프로젝트 복구 경로와 실행·미검증 상태가 기록됨
