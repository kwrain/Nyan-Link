# [기획서] 냥링크: 01. 개요 및 구성

## 1. 개요 (Overview)

- **프로젝트명**: 냥링크 (Nyan Link)
- **장르**: 하이브리드 퍼즐 RPG (러너 & 시퀀스 퍼즐 + **수집형 RPG**)
- **엔진**: Unity 6.0+
- **기술 스택 (Tech Stack)**:
    - **Puzzle Rendering**: **Unity Tilemap (Hexagonal Pointy-top)** - 모바일 최적화 배치 적용
    - **UI System**: **Unity UI Toolkit (UXML/USS)**
    - **Input System**: New Input System Package
    - **External Packages**:
        - **NineMood.Services**: 유니티 서비스(Ads, Crashlytics, Analytics) 통합 패키지.
        - **NineMood.LocalDB**: 밸런싱 데이터(Spreadsheet)를 ScriptableObject로 변환 및 관리.
- **플랫폼**: 모바일 (Android / iOS) - **Portrait (세로 모드)**
- **핵심 재미 (Core Fun)**:
    - **액션 퍼즐**: 러너 액션을 발동시키는 타일 제거의 긴박함과 보스 패턴 공략.
    - **파밍 & 성장**: 스테이지 보스를 공략하여 **'보스 전용 장비'**를 수집하고 캐릭터를 성장시키는 RPG의 재미.
    - **몰입감**: 아케이드 모드에서 시간에 쫓기지 않고 순수하게 퍼즐 매칭을 즐기는 경험.

## 2. 화면 구성 (Screen Layout)

화면을 **상하 40:60 비율**로 분할하여 구성합니다.

### 2.1. 상단 뷰 (Runner View) - [40%]

- **역할**: 스테이지 진행 상황 및 장애물/보스 전투 시각화.
- **구성 요소**:
    - **Player Character**: 상황(장애물/보스)에 따라 점프, 슬라이딩, 공격 등의 액션을 수행하는 고양이.
    - **Background**: 에피소드 테마에 따른 패럴랙스 배경.
    - **Progress Bar**: 스테이지 시작 지점부터 보스 출현 지점까지의 진행률 표시.
    - **Event Zones**:
        - **Obstacle Zone**: 정해진 구간에서 등장하는 장애물.
        - **Boss Zone**: 진행률 100% 도달 시 등장하는 스테이지 보스.
    - **Status UI**: 현재 스태미나(HP) 및 보스전 관련 정보(남은 시간, 패턴 UI 등).

### 2.2. 하단 뷰 (Puzzle Controller) - [60%]

- **역할**: 헥사곤 타일 조작 및 액션 트리거.
- **구성 요소**:
    - **Hexa Grid (Honeycomb Layout)**: 5x6 ~ 6x7 가변형 헥사곤 그리드.
    - **Action Feedback**: 특정 타일 매칭 시 상단 캐릭터가 수행하는 액션 이펙트 표시.

## 3. 게임 모드 (Game Modes)

### 3.1. 어드벤처 모드 (Adventure Mode)

- **설명**: 러너 액션, 퍼즐, 그리고 **장비 파밍**이 결합된 메인 모드입니다.
- **진행**: 시작 → 장애물 구간 돌파 → 보스 조우 → 보스 클리어 → **전리품 획득**.
- **목표**:
    1. 스태미나가 0이 되지 않고 보스를 처치하여 스테이지 클리어.
    2. 보스 처치 시 드롭되는 **[보스 전용 장비]**를 획득하여 세트 완성.

### 3.2. 아케이드 모드 (Arcade Mode)

- **설명**: 상단의 러너 액션 및 장애물 스트레스 없이 **하단 퍼즐 플레이에 집중**하는 모드.
- **변경점**: 장애물 및 보스가 등장하지 않으며, 순수 점수 경쟁(Time Attack)으로 진행.
